# Expense Tracker

A React app for recording income and expenses, categorizing transactions, and tracking the balance in INR.

## Run locally

```sh
npm ci
npm start
```

`npm run build` creates a production bundle. Transactions persist in this browser using localStorage; clearing site data removes them. There is no server sync or account system. Decimal amounts are supported; use negative values for expenses. Avoid entering sensitive financial details on a shared device.
